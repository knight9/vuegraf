API / AI access

Admin

Start here

Use this authenticated HTTP API, not SSH or Docker. Download the OpenAPI specification. One username/password accesses both the UI and API. HTTP does not encrypt credentials or data: use only on your trusted home network. Do not expose this service publicly.

curl -u "$VUEGRAF_ADMIN_USERNAME:$VUEGRAF_ADMIN_PASSWORD" http://HOST:8080/api/discovery
curl -u "$VUEGRAF_ADMIN_USERNAME:$VUEGRAF_ADMIN_PASSWORD" http://HOST:8080/api/status
curl -u "$VUEGRAF_ADMIN_USERNAME:$VUEGRAF_ADMIN_PASSWORD" http://HOST:8080/api/coverage

Status reads are cached and do not contact Emporia. Circuits have opaque IDs, account/device/channel identifiers and display names. Available history varies by circuit; a successful collection does not imply complete source coverage.

One-shot collection

# Current minute (also runs bounded recovery and refreshes cached storage/coverage)
curl -u "$VUEGRAF_ADMIN_USERNAME:$VUEGRAF_ADMIN_PASSWORD" \
  -H 'Content-Type: application/json' -H 'X-Vuegraf-Request: 1' \
  -d '{}' http://HOST:8080/api/collect/minute

# Last completed UTC hour
curl -u "$VUEGRAF_ADMIN_USERNAME:$VUEGRAF_ADMIN_PASSWORD" \
  -H 'Content-Type: application/json' -H 'X-Vuegraf-Request: 1' \
  -d '{}' http://HOST:8080/api/collect/hour

# Previous local calendar day (using the configured collector timezone)
curl -u "$VUEGRAF_ADMIN_USERNAME:$VUEGRAF_ADMIN_PASSWORD" \
  -H 'Content-Type: application/json' -H 'X-Vuegraf-Request: 1' \
  -d '{}' http://HOST:8080/api/collect/day

# Bounded second refresh
curl -u "$VUEGRAF_ADMIN_USERNAME:$VUEGRAF_ADMIN_PASSWORD" \
  -H 'Content-Type: application/json' -H 'X-Vuegraf-Request: 1' \
  -d '{"lookback_seconds":300,"circuits":[]}' http://HOST:8080/api/collect/second

These are the same minute, second, hour and day loops used by the scheduler. A manual run does not postpone the next scheduled run. 202 means admitted; 409 means busy/not ready and includes current status. All types share one collector mutex and there is no job queue. For seconds, empty circuits selects all; otherwise use IDs from discovery. Maximum lookback is 10,800 seconds. Poll status to distinguish running, success, partial, failed and interrupted results. Missing/unsupported samples are not zeros.

Download data for tools

curl -u "$VUEGRAF_ADMIN_USERNAME:$VUEGRAF_ADMIN_PASSWORD" \
  -H 'Content-Type: application/json' -H 'X-Vuegraf-Request: 1' \
  -d '{"start":"2026-09-19T00:00:00Z","stop":"2026-09-19T01:00:00Z","resolution":"minute","field":"power_watts","aggregate":"mean","window":"5m"}' \
  http://HOST:8080/api/export -o readings.csv

Analyze the CSV with local tools rather than placing every row into chat context. Filters: account, device, channel. Fields: power_watts (W), voltage_volts (V), current_amps (A), energy_kwh (kWh), charge_ah (Ah). UTC timestamps; stop is exclusive. One resolution per request. Date limits: seconds 30 days, minutes 730 days, hours/days 1,825 days. These are query limits, not guarantees of available data.

Aggregations: raw, mean, min, max; sum only for energy/charge. Windows: 1m, 5m, 15m, 1h, 1d, never finer than the source. Aggregation is per series, UTC-aligned, and skips missing windows. Means are arithmetic means of available samples, not gap-filled time-weighted estimates. Original daily samples follow collector timezone/DST; avoid treating a local day as always 24 hours.

Do not double-count different resolutions, mains plus branches, or merged circuits plus their legs. At most two exports can run/download concurrently; each is capped at 100,000 rows, 32 MiB and 15 seconds. Oversized exports fail, not silently truncate. Temporary files close after download. Prefixes may be added to textual tags to prevent spreadsheet formula execution.

401: authentication required; 403: missing action header/cross-origin; 400: invalid query or exceeded limits; 429: exports busy; 502: database error. No arbitrary Flux, shell, database deletion, or Docker administration endpoint is provided.
